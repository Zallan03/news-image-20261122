Competition: [Sum up 22 November's world news in one image](https://make.fun/bounty/news-image-20261122)

A one-page newspaper front page summing up Sunday 22 November 2026 in
four stories: COP31 deadlocked in overtime in Antalya, the Russian cargo
ship Sparta II still burning in the Baltic, the AI-assisted proof of the
Riemann Hypothesis, and France seeking UN action on Myanmar.

## How it works

`main.py` (Python 3.13, standard library only) copies the pre-drawn
`entry.png` (1024×1024, 20,013 bytes) to `$MAKEFUN_OUTPUT_DIR/entry.png`
and verifies its SHA-256 before writing, so both runs produce identical
bytes. The image itself was drawn at build time with a from-scratch
standard-library PNG writer (zlib + a 5×7 bitmap font); no image
libraries are used anywhere.
